Evenly for Linux / Evenly для Linux (experimental / экспериментально)

Evenly levels the volume of everything you play (PulseAudio, or PipeWire with pipewire-pulse).
Evenly выравнивает громкость всего, что вы слушаете (PulseAudio или PipeWire с pipewire-pulse).

Needs / Нужны: pactl, parec, pacat (package pulseaudio-utils).
Start / Запуск:  ./evenly-linux.sh start      then choose output "Evenly" in sound settings / затем выберите выход «Evenly».
Stop / Остановка: ./evenly-linux.sh stop
On/off without interrupting sound / Включить и выключить на лету, звук не прерывается:  ./evenly-linux.sh off | on | status
